# RABBIT HOLE PITCH — Cómo dejar que el proyecto hable por mí

> Este documento es una hoja de ruta para convertir Tiny Theme Studio en una carta de presentación real.
> Sin CV tradicional. Sin experiencia formal. Sin venderme con palabras.
> Solo el trabajo.

---

## El contexto

- 50 años, artesana y pintora reconvertida en desarrolladora frontend
- Sin experiencia laboral formal en tecnología
- Con un nivel de inglés, una esencia creativa y un criterio visual que pocos devs de 25 tienen
- No me gusta hablar de mí misma ni venderme

**La solución: que el proyecto hable solo.**

---

## Lo que el proyecto ya transmite (sin que lo diga nadie)

- Un sistema de tokens CSS hecho a mano — modos, moods, capas
- Angular moderno: signals, standalone, arquitectura limpia
- i18n real (español, inglés, alemán)
- Accesibilidad: `prefers-reduced-motion`, contraste por tokens, HTML semántico
- Responsive moderno con `clamp`, flex y grid — sin media queries innecesarios
- Un README bilingüe con voz propia y personalidad
- Una narrativa (Alicia en el País de las Maravillas) que lo hace memorable
- Criterio: sabe por qué hace cada decisión

---

## El problema a resolver

El proyecto es bueno, pero **tiene que entenderse en 30 segundos.**

Un recruiter que no sabe nada de CSS tokens tiene que mirar esto y pensar:
_"esta persona sabe lo que hace y tiene algo especial"_.

---

## Plan de acción

### 1. README — primera línea que engancha

- Reescribir la apertura para que cualquier persona (técnica o no) entienda qué es y por qué importa
- Añadir un párrafo "About the author" corto, honesto, sin victimismo

### 2. Welcome section — que la narrativa cuente quién eres

- La sección `conclusion` ("La Declaración de Sara") es el momento más personal
- Revisar que comunique esencia, no solo código

### 3. Style guide — que sea tan bonita que se venda sola

- Debe impresionar visualmente en el primer vistazo
- Es la demo técnica y artística al mismo tiempo

### 4. Párrafo "About" — corto, bilingüe

- Inglés y español
- Sin pedir disculpas por la edad ni por no tener experiencia
- Enfocado en lo que SÍ hay: criterio, curiosidad, oficio

### 5. GitHub — que el repo también venda

- Descripción del repo clara y atractiva
- Topics relevantes: `angular`, `css-tokens`, `design-system`, `typescript`, `frontend`
- og-image (imagen de preview cuando se comparte el link)
